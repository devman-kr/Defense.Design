# 목업 — 룩앤필 확인용

게임 엔진 없이 브라우저에서 화면 흐름 · 색 · 조명 · 전환 타이밍을 미리 보는 가벼운 목업이다. 게임 저장소에 들어가지 않고, 「이 느낌이 맞나」를 판단하는 데만 쓴다.

**규칙**
- 목업 하나가 HTML 파일 하나다. 외부 라이브러리는 CDN 에서 정확한 버전으로 불러오고 저장소에 내려받아 두지 않는다. 라이선스를 확인한다(three.js — MIT, 글꼴 Jua — OFL).
- 목업에서 정한 색 · 시간 값 중 게임으로 가져갈 것은 기획서나 `../데이터/` 에 옮긴다. 목업 코드는 게임 코드로 옮기지 않는다.
- 레퍼런스 게임의 에셋 · 캡처를 넣지 않는다.
- 파일은 claude.ai 페이지 규격(문서 뼈대 태그 없이 본문부터)으로 쓴다. 로컬에서 열어도 레이아웃은 스크립트가 맞춘다.

| 목업 | 보여 주는 것 | 방식 | 상태 |
|---|---|---|---|
| [낮의 섬 하루 순환](낮의섬_하루순환.html) | 낮의 섬(강화 · 꾸미기 · 설정) → 「하루 보내기」 → 저녁 → 밤(사방에서 슬라임 · 석궁 자동 공격 · 경험치 · 카드 3장 · 낙뢰 · 회전 칼날 · 화염구 · 엘리트) → 「새벽이 밝았다!」(계속 버티기 · 아침 맞기) → 정산(모의 광고 2배) → 아침. 패배(등불이 꺼짐) · 첫 실행(튜토리얼 판) · 자동 시연 | HTML 한 파일 + three.js r128(cdnjs) · 글꼴 Jua(Google Fonts) | v1(2026-10-30) — 사용자 확인 ✔ |

## 보는 법

- **claude.ai 비공개 페이지**: https://claude.ai/artifact/XFMZ5htvQBv2Ej7bN69Mrp — 휴대폰에서 세로로 볼 수 있다. 본인과 공유받은 사람만 열린다.
- **로컬**: 파일을 브라우저로 연다. 인터넷 연결이 필요하다(three.js · 글꼴을 CDN 에서 받는다).
- **바로 가기**(주소 끝 `#…`): `#day` 낮의 섬 · `#first` 첫 실행 · `#demo` 자동 시연(자동 선택 · 배속 ×2 로 한 바퀴씩 반복) · `#night` 밤 10:00 · `#dawn` 새벽 직전 · `#defeat` 패배 · `#shop` 강화 · `#deco` 꾸미기.

## 실제 게임과 다르게 한 것

- 밤 30분을 실제 약 45초(×1)로 줄였다. 낙뢰 쿨다운은 30초 → 6초, 엘리트는 네 번(5:00 · 12:30 · 20:00 · 27:30)만 나온다.
- 섬 둘레를 하늘(떠 있는 섬)로 했다 — 하루 조명의 변화가 하늘색으로 크게 보이게. 바다로 할지는 검토 거리다.
- 모델은 전부 기본 도형이고, 수치 · 밸런스에는 뜻이 없다.
- 보통 판에서는 30:00 전에 탑 체력이 30% 밑으로 내려가지 않게 막아 두었다(새벽까지 보이게). 「패배 보기」 · 「계속 버티기」에서는 풀린다.
