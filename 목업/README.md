# 목업 — 룩앤필 확인용

게임 엔진 없이 브라우저에서 화면 흐름 · 색 · 조명 · 전환 타이밍을 미리 보는 가벼운 목업이다. 게임 저장소에 들어가지 않고, 「이 느낌이 맞나」를 판단하는 데만 쓴다.

**규칙**
- 목업 하나가 HTML 파일 하나다. 외부 라이브러리는 CDN 에서 정확한 버전으로 불러오고 저장소에 내려받아 두지 않는다. 라이선스를 확인한다(예: three.js — MIT).
- 목업에서 정한 색 · 시간 값 중 게임으로 가져갈 것은 기획서나 `../데이터/` 에 옮긴다. 목업 코드는 게임 코드로 옮기지 않는다.
- 레퍼런스 게임의 에셋 · 캡처를 넣지 않는다.

| 목업 | 보여 주는 것 | 방식 | 상태 |
|---|---|---|---|
| 낮의 섬 하루 순환 | 낮의 섬 → 「하루 보내기」 → 저녁 → 밤(괴물이 몰려옴 · 자동 공격 · 카드 3장) → 새벽 · 정산 → 낮. 패배(등불 꺼짐) · 첫 실행 · 배속 토글 | HTML + three.js(3D 로우폴리, 9:16) | 계획 — 사용자 착수 승인 대기 |
